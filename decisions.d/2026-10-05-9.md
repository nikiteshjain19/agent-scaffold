# D-9 — 2026-10-05 — A plugin-namespaced skill satisfies a bare-name citation

- **Decision:** A skill the session lists as `<plugin>:<name>` is the skill `<name>`, and it
  satisfies every bare-name citation of it, in every document. The prefix belongs to the installer
  and is not part of the skill's identity. The bare name stays the address that documents write.
  An agent never concludes a skill is missing because the session lists it only with a prefix.
  `CLAUDE.md` §12 states the rule, in its paragraph "A namespaced entry is the skill it names", as
  merged by PR #28 (`0c3980c`).
- **Context:** A plugin always namespaces its skills (D-1), so a session that installs the `hivion`
  plugin lists `hivion:pr-reviewer`, never `pr-reviewer`. An agent that matched the bare name as an
  exact string against that list concluded the skill was not installed. Escalation condition 6
  then fired on every pull request, because no independent reviewer was available to return an
  approve. That reads as a correct fail-closed result and is not one: it is the same failure §12
  already named for an agent that looks for a skill by path. The `pr-merge-loop` skill's LANE
  AVAILABILITY question 3 was the only place in `skills/` that tested whether a skill is
  invocable, so PR #28 reconciled it in the same change.

  **Why the bare name stays the address.** Writing `hivion:pr-reviewer` into the documents would
  tie every citation to one install route. A repository that installs the skills into its own
  `.claude/skills/`, or into a personal skills directory, lists them without a prefix, and every
  prefixed citation would then resolve to nothing. The name is what travels; the prefix depends on
  how the skill arrived.

  **Why this entry is late.** PR #28 made the judgment call, and `CLAUDE.md` §7 asks for it to be
  logged. `decisions.d/` was outside #9's declared footprint, so PR #28 deferred the entry and named
  it as a follow-up. #29 records it.
- **Affects:** `CLAUDE.md` §12; the `pr-merge-loop` skill, LANE AVAILABILITY; #9; PR #28.
