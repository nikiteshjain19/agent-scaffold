# D-103b — 2026-10-13 — PROJECT.md stays free of agent-dispatch tooling

- **Decision:** `PROJECT.md` carries nothing about the tooling that dispatches agents to this
  repository. No such fact is added anywhere in this document, and none is added anywhere else in
  the repository.
- **Context:** #103. The owner considered recording the dispatch tooling in `PROJECT.md`, "Toolchain",
  and declined. `PROJECT.md` describes this repository and the tracker its issues live in; which
  platform starts an agent run is a property of that platform, not of this repository, so it has no
  place in a document that describes the repository itself.
- **Affects:** `PROJECT.md` ("Toolchain"); #103.
